# PlantsVSZombies
Plants vs. Zombies terminal simulation developed as part of the Programming Technology I course, belonging to the Computer Engineering degree at Universidad Complutense de Madrid (UCM).

The project implements a text-based version of the game using Java, featuring a command-line interface (CLI) where players manage resources and units on a grid-based board. It focuses on the application of Object-Oriented Programming (OOP) principles, such as inheritance and polymorphism, to manage the interaction between different types of plants and zombies.

This project was developed in collaboration with Sergio Martínez Olivera (https://github.com/sergiio8).
